# 💰 Expense Tracker App (Frontend)

A modern, dynamic, and responsive React frontend application for tracking daily expenses and incomes, visualizing spending patterns, and managing personal finances.

---

## 📌 Note for Viewers & Recruiters
This repository contains the **Frontend UI code** for the Expense Tracker application. The project is split into two separate repositories (Frontend and Backend) to maintain clean separation of concerns and independent deployment pipelines.
* **Backend Repository:** [Expense-Tracker-Backend](https://github.com/sahilsharma2246/Expense-Tracker-Backend)
* **Live Application:** [Click here to view Live Site](https://illustrious-meerkat-829958.netlify.app)

---

## ✨ Features
- **User Authentication:** Secure JWT-based Login and Registration interface.
- **Dashboard Overview:** Displays total income, total expense, and net balance in real time.
- **Transaction Management:** Add, filter, and delete transactions effortlessly.
- **Category & Date Filters:** Sort expenses by custom dates and specific categories.
- **Responsive UI:** Clean dark-themed design built with Tailwind CSS.

---

## 🛠️ Tech Stack
- **Library:** React.js
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Deployment:** Netlify
